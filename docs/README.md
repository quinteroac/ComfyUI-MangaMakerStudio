# Manga Maker Studio documentation

[Project README](../README.md)

These guides explain how the workspace is organized, which settings affect each operation, and how to choose a workflow. They are organized by task rather than a numbered tutorial.

| Guide | What it covers |
| --- | --- |
| [Installation and dependencies](installation.md) | Installing Studio, required custom nodes, optional features and weights |
| [Agent-assisted setup](agent-setup.md) | The setup skill, example requests, agent access and verification |
| [Configuration](configuration.md) | Global models, per-operation overrides, presets, text/vision settings and output size |
| [Using Studio](usage.md) | References, panels, image actions, refinement and finishing |
| [Drawing and manga conversion](drawing.md) | Klecks, Sketch to Art, Art to Manga Panel, regions, masks and layered saving |
| [Page layout](page-layout.md) | Composition, panel framing, dialogue, fonts and export |
| [Projects and storage](projects.md) | Versions, Trash, saving, migration, jobs and common problems |
| [Credits and attribution](credits.md) | Upstream projects, contributors, workflow sources and license notices |
| [Development and validation](development.md) | Bundled editor build, test commands and validation scope |

For a drawing-only or page-layout workflow, start with the usage guides; diffusion models are not needed until you run generation or model-based editing. For AI features, read Installation and Configuration first. Art to Manga Panel's Manga-Lite mode needs MangaScreen but no diffusion model.

Screenshots show the actual plugin UI with demonstration assets in isolated storage. They illustrate controls and organization, not model output quality.
